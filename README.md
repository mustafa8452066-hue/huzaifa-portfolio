# Huzaifa – Cricket Portfolio

Files: index.html (structure) · style.css (design) · script.js (features) · images/

## Run locally
1. Unzip the folder.
2. Double-click `index.html` – it opens in your browser. No install needed.
   (Needs internet only for the Google Fonts; works without it with fallback fonts.)
   Optional: in VS Code, right-click index.html > "Open with Live Server".

## Add real contact details
Open `script.js`, edit the CONFIG block at the very top (email, whatsapp, instagram...).
Empty = hidden automatically. WhatsApp format: country code + number, e.g. 919876543210

## Edit skill levels
In `index.html`, find "Cricket Skills" and change the numbers in data-level="80" and the % text beside it.

## Change photos
Replace files inside `images/` keeping the same names (hero.jpg, bat.jpg, ball.jpg, stump.jpg).

## Publish free on GitHub Pages
1. github.com > New repository > name it e.g. `huzaifa-portfolio` (Public).
2. "uploading an existing file" > drag ALL files (index.html, style.css, script.js, images folder) > Commit.
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After ~1-2 minutes the link is: https://YOUR-USERNAME.github.io/huzaifa-portfolio/
